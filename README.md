# AI Sales Corp

Шаблонный корпоративный сайт продаж для ChatGPT Sites (Cloudflare Worker + D1 + R2). Пять разделов на общей базе: Обучение, CRM, KPI, Статистика, WhatsApp Studio.

Публикация, привязки, миграции, секреты и активация директора описаны в **[README_SITES.md](README_SITES.md)**.

## Структура

```text
app/, components/     страницы и интерфейс (App Router на vinext)
  app/api/[...path]   единая точка API → server/router.ts
components/ui/        компоненты в стиле shadcn/ui
server/               серверные операции, сессии, проверка прав (access.ts)
  handlers/           обработчики API по разделам
db/schema.ts          схема БД (Drizzle)
drizzle/              SQL-миграции (не правятся после применения)
config/company.ts     название, логотип, палитра, шрифты, плотность, воронка, правила допуска
i18n/ru.ts            все тексты интерфейса и сервера (kk/en добавляются рядом)
lib/hotkeys.ts        единый список горячих клавиш
worker/index.ts       вход Worker'а
.openai/hosting.json  привязки DB и BUCKET
test/                 серверные сценарии на node:sqlite (эмуляция D1)
e2e/                  браузерные сценарии (Playwright)
```

## Разработка

```bash
npm ci
cp .env.example .dev.vars   # заполните OWNER_ACTIVATION_CODE
npm run dev                 # http://localhost:5173, локальная D1 в .wrangler/state
npm test
npm run build
```

## Интерфейс

Оформление и расположение экранов повторяют систему AI Management, чтобы работать в обеих было одинаково привычно:

- слева панель: квадрат с первой буквой и название компании, разделы с иконками (Обучение, CRM, KPI, Статистика, WhatsApp Studio), внизу «Настройки системы» и «Профиль»;
- шапка страницы: заголовок слева, филиал справа (у директора — список с «Все филиалы», у остальных — название своего филиала);
- таблицы в карточках с заголовками капсом, метки статуса с точкой, вкладки с подчёркиванием, подсказка `Ctrl+Enter` внутри кнопки сохранения;
- страницы входа — одна карточка по центру.

Компоненты лежат в `components/ui`, цвета — в `config/company.ts` (`palette`).

## Роли и права

| Роль | Доступно |
|---|---|
| Сотрудник до допуска | Обучение, профиль |
| Сотрудник после допуска | CRM, личный KPI, обучение, профиль |
| Руководитель филиала | Свой филиал: обучение сотрудников, CRM, KPI, статистика, WhatsApp Studio; в «Настройках системы» — участники и приглашения |
| Директор | Вся компания. «Настройки системы»: компания, филиалы, участники, приглашения, подключения. Филиал выбирается в шапке; «Все филиалы» — в обучении, статистике и настройках |

Права проверяются на сервере при каждом запросе (`server/access.ts`). Роль, филиал и допуск читаются из БД заново, поэтому перевод сотрудника, снятие роли или допуска действуют со следующего запроса.
